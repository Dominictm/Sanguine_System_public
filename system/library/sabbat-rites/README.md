# Библиотека обрядов Шабаша V20

Канонический источник: **по одному MD-файлу на запись**.
Сервер (`web/routes/library.js` → `_mdLibRoutes`, apiName `sabbat-rites`) парсит эти
файлы (схема «Секты»: шапка + `## Описание`), отдаёт по
`GET /api/library/sabbat-rites`, веб рендерит (страница «Вампиры» →
подвкладка «Обряды»).

Формат — как `sects/README.md`: `# <эмодзи> Название`, строки
`- **Тип:**` (священный / мирский / основополагающий) и `- **Источник:**`,
опц. цитата `>`, `## Описание` (лор + механика проведения — пересказ
своими словами, не копипаста).

Общее правило всех обрядов: отправить обряд теоретически может кто угодно,
но эффект наступает, только если ведущий обладает фактом биографии
«Обряды» — без знания мистической подоплёки ритуал не работает.

## Статус наполнения

14 записей: 9 священных по Приложению V20 (печатные ~549–553), 4 мирских
(печатная 554) и Братание (гл. 6, стр. 319; тип «основополагающий»).

> Примечание: `README.md` сервером пропускается (не запись).
