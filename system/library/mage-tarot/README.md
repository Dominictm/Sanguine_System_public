# Маги · Таро (`mage-tarot`)

Отдельная подвкладка «Таро» раздела «Маги»: колода Таро Мага как игровой
инструмент — гадание, подсказки сюжета и характеристика фракций.
Канонические записи — пересказ своими словами (Dark Pack Agreement).

Состав: 22 Старших Аркана + 56 Младших в четырёх мастях:
Искание (Жезлы/Традиции/Огонь), Изначальность (Чаши/Нефанди/Вода),
Динамизм (Мечи/Мародёры/Воздух), Узор (Пентакли/Технократия/Земля).

Формат:

```markdown
# Название (English)

- **Аркан:** Старшие
- **Значение:** Возможность
- **Перевёрнутая:** Застой
- **Ассоциация:** Мародёры
- **Источник:** Таро Мага, гл. 2 «Старшие Арканы»

**Литературное описание.** Образ карты своими словами.

**Система.** Прямое и перевёрнутое значение + применение за столом.
```

Поля API: `arcana`, `meaning`, `reversed`, `association`, `description`, `system`.
Фильтр подвкладки — чипы по Аркану + поиск RU/EN.
