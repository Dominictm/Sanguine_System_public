# Библиотека Путей Просветления V20

Канонический источник: **по одному MD-файлу на запись**.
Сервер (`web/routes/library.js` → выделенные CRUD-роуты `paths`, apiName
`vampire-paths`) парсит эти файлы (схема «Секты»: шапка + `## Описание` +
таблица `## Иерархия грехов` → `sins`), отдаёт по
`GET /api/library/paths`, веб рендерит (страница «Вампиры» →
подвкладка «Пути»).

Формат — как `sects/README.md`: `# <эмодзи> Название`, строки
`- **Прозвище:**` / `- **Добродетели:**` / `- **Столп:**` /
`- **Источник:**`, опц. цитата `>`, `## Описание` (идеология + этика +
абзац истории — пересказ своими словами, не копипаста),
`## Иерархия грехов` (ровно 10 строк, рейтинги 10→1; у Человечности
таблица из 2 колонок, у путей — из 3).
