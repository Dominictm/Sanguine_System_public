# Время (Time)

- **Источник:** Подменыши: Грёза (Changeling: The Dreaming, 2-я ред.), стр. 294

## Описание

Позволяет «откладывать» действие колдовства. Заклинатель накладывает колдовство, покидает место, ждёт результата в безопасности. Уровень = задержка и модификатор сложности.
