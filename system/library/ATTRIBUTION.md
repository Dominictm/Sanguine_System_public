# Атрибуция JSON-данных библиотеки

> Для соблюдения Dark Pack Agreement (Блок C, `docs/design/2026-08-26-licensing-workplan.md`):
> элементы `system/library/` должны ссылаться на первоисточник — книгу и страницу.
>
> Номера страниц — **русское печатное издание V20** (PDF − 10; печатная-top метка каждой страницы).
> Атрибуция категорийная: записи JSON не сопоставляются поимённо с переводом книги —
> названия в JSON взяты из другого перевода (wod.su), поэтому точную страницу конкретной записи
> установить без сверки нельзя. По правилу «неверная ссылка хуже отсутствующей» указывается
> категория и страница начала раздела.

## Комбо-дисциплины (system/library/combo_disciplines.json)

**Источник не установлен.** Раздела комбо-дисциплин нет в русском печатном V20 Core
(поиск по тексту издания не находит ни раздела, ни входящих в JSON способностей).
Часть комбо происходит из кланбуков (CB Lasombra, CB Tzimisce и др.), но для конкретных
записей это не проверено поимённо. Пока источник не установлен — не указывается
(правило: «неверная ссылка хуже отсутствующей»). Требуются кланбуки или английский V20.
