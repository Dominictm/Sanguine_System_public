# Библиотека семей ревенантов V20

Канонический источник: **по одному MD-файлу на семью**.
Сервер (`web/routes/library.js` → `_mdLibRoutes`, apiName `revenant-families`,
поле шапки `Дисциплины`) парсит эти файлы, отдаёт по
`GET /api/library/revenant-families`, веб рендерит (страница
«Гули и ревенанты» → «Семьи»).

## Формат файла

```markdown
# 🐺 Братовичи (Bratovichi)

- **Дисциплины:** Анимализм, Превращение, Стойкость
- **Источник:** V20, стр. 544

> (опц.) короткая цитата-эпиграф

## Описание

<текст — своими словами, не копипаста; в конце — «Изъян» семьи>
```

Поле `Дисциплины` — традиционные Дисциплины семьи (нужны созданию
персонажа-гуля). Изъян — в теле описания.

## Статус наполнения

9 семей по Приложению V20 (печатные ~544–548): Братовичи, Гримальди,
Дучески, Зантоза, Обертусы, Опричники + краткие Даниславы, Зантовичи,
Мариджава (по строке «других семей»).

> Примечание: `README.md` сервером пропускается (не семья).
