# 👁️ Зантовичи (Zantovich)

- **Источник:** V20, стр. 548

> Трансильванские шпионы и лазутчики — союзники сразу нескольких вампирских кланов.

## Описание

Одна из малых семей из перечня «других»: сведений в книге — строка. Ремесло — шпионаж; работодатели — разные кланы. Подробности — на усмотрение Рассказчика.
