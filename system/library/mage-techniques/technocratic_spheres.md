# Технократические Сферы (Technocratic Spheres)

- **Источник:** Маги: Восхождение. Классические правила, ч. II «Сферы»

## Описание

У Союза свой взгляд на три Сферы: Данные вместо Связей (Новый Мировой Порядок), Первичная Польза вместо Первоосновы (Синдикат, гиперэкономика), Пространственная Наука вместо Духа (Инженеры Пустоты). Доступны, как правило, только оперативникам — кроме Данных, ушедших к техномантам по обе стороны. Мистический аналог одновременно не удержится: взгляды противоречивы.

**Система.** Те же правила, что у мистических аналогов, с особыми преимуществами и ограничениями каждой Конвенции.
