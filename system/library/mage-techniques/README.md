# Формат записей техник (`mage-techniques`)

Обзорный справочник творения эффектов: карточки без уровней.

```markdown
# Название

- **Источник:** Маги: Восхождение. Классические правила, ч. II

## Описание

Текст своими словами.

**Система.** Механика текстом (если применимо).
```

Поля API: `description`, `system`.
