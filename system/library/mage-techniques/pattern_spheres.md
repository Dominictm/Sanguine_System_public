# Сферы Узора (Pattern Spheres)

- **Источник:** Маги: Восхождение. Классические правила, ч. II «Сферы»

## Описание

Три Сферы правят вещественным: Жизнь лепит органику, Материя — неорганику, Силы — энергию. Дух причисляют к ним условно — он правит эфемерой, метафизической материей Умбры. Творя огонь, бабочек, камень или призрачный клинок из ничего, маг сочетает Сферу Узора с сырой энергией Первоосновы: первая даёт форму, вторая — реальность.

**Система.** Создание из ничего: Сфера Узора + Первооснова (уровень — по таблице «Распространённые магические Эффекты»).
