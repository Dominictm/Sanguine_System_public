# Маги · Чудеса (`mage-wonders`)

Подвкладка «Чудеса»: зачарованные предметы — талисманы, периапты,
фетиши. Пересказ своими словами (Dark Pack Agreement).

```markdown
# Название (English)

- **Тип:** Талисман
- **Сила:** 3 точки
- **Источник:** Руководство по Традициям, гл. 8 «Сокровища»

**Литературное описание.** Вид и легенда предмета своими словами.

**Система.** Эффект и цена текстом.
```

Поля API: `type`, `power`, `description`, `system`.
