# Чётки Воина (Warrior's Beads)

- **Тип:** Перияпт
- **Сила:** 2 точки
- **Источник:** Книга Братства Акаши, гл. «Магия»

**Литературное описание.** Простые деревянные чётки, истёртые тысячами переборов в медитациях и тренировках. Каждая бусина впитала каплю дисциплины владельца, и вместе они держат запас силы для трудного часа.

**Система.** Чётки хранят несколько очков квинтэссенции, накопленной медитацией и дыхательными практиками. Владелец черпает из запаса для телесных и боевых эффектов. Чужая рука не может открыть запас без обучения.
