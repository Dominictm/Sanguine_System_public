# Наладонник Плеромы (Pleroma Assistant)

- **Тип:** Талисман
- **Сила:** 2 точки
- **Источник:** Руководство по Традициям, гл. 8 «Сокровища»

**Литературное описание.** С виду обычный карманный компьютер с потёртой крышкой, какие носили в конце прошлого века. Внутри — неприметный модуль, открывающий доступ к скрытой сети кабалов: почте, картам узлов и библиотеке.

**Система.** Владелец, посвящённый в сеть, получает связь, доступ к общим сведениям и переписке кабалов. Посвящение требует присутствия того, кто уже подключён. Потерянный прибор для непосвящённого — просто старая электроника.
