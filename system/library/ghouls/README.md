# Библиотека гулей V20

Канонический источник: **по одному MD-файлу на запись**.
Сервер (`web/routes/library.js` → `_mdLibRoutes`, apiName `ghouls`) парсит эти
файлы (схема «Секты»: шапка + `## Описание`), отдаёт по
`GET /api/library/ghouls`, веб рендерит (страница «Гули и ревенанты» →
«Гули»).

Формат — как `sects/README.md`: `# <эмодзи> Название`, строки
`- **Источник:**`, опц. цитата `>`, `## Описание` (лор + механика —
создание, правила, шаблоны — пересказ своими словами, не копипаста).

## Статус наполнения

7 записей по Приложению V20 (Гули, печатные ~536–544): типы гулей,
создание персонажа-гуля, свод правил (узы/Дисциплины/старение/исцеление/
ярость/изъяны/передозировка/воздержание/Становление), шаблоны Шляхты и Вождя.

> Примечание: `README.md` сервером пропускается (не запись).
