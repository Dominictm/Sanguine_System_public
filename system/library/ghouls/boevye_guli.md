# ⚔️ Боевые гули (War Ghouls)

- **Источник:** V20, стр. 543

> Пушечное мясо Цимисхов на случай войны и охрана владений. Кое-где разводят до сих пор — и врагам Нелюди приходится их учитывать.

## Описание

Штампованные ужасы ваятелей плоти: лоботомированные полузвери на приказах, кошмарные карикатуры на живое. Страх, который они сеют, — тоже оружие: порой одного их вида хватает для перелома битвы. А назад, к людям, им дороги нет — остаётся служба, которой они славятся.
