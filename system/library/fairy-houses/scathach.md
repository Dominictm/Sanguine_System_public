# Дом Скатах (House Scathach)

- **Благо:** Безмолвные воители — +1 кубик к Драке и Фехтованию; Маскировка −1
- **Порок:** Презрение аристократов — Социальные +2 (+4 с традиционалистами); запрет Искусства Правления самой Грезой
- **Предрасположенность:** Природа
- **Источник:** Дополнительные книги линейки Changeling: The Dreaming (без указания страниц)

## Описание

Молчаливые воины-одиночки: в бою впадают в странное замедление времени, двигаясь с прежней скоростью среди застывших врагов. Держатся особняком, презирают придворные игры. Аристократы смотрят на них сверху вниз — древний кровавый договор запрещает им Искусство Правления. Вернувшимся с Аркадии приходится скрывать принадлежность к дому.
