# Феи · Дома

Канонические записи — пересказ своими словами (Dark Pack Agreement), по файлу на запись.

Формат:

```markdown
# Название (English)

- **Благо:** …
- **Порок:** …
- **Источник:** Книга, стр. N

## Описание

Текст своими словами.
```

Авторская запись дополнительно несёт `- **Авторское:** да` и создаётся из веба (Библиотека).
