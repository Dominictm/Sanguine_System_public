# Царства Парадокса (Paradox Realms)

- **Слой:** Глубокая Умбра
- **Источник:** Книга Миров, гл. «Загадки»

**Литературное описание.** Карманы мироздания, куда реальность запирает магов, слишком дерзко нарушивших её законы. Каждое такое царство скроено по мерке вины пленника: глупец бродит в тумане беспамятства, гордец правит пустым троном, бунтарь воюет в войне без конца. Снаружи они могут казаться пустяком, изнутри — вечностью.

**Система.** Сюда не ходят по своей воле, сюда ссылают: тяжкий провал магии или приговор собратьев. Выбраться можно лишь усвоив урок места, что для гордого мага страшнее любой пытки. В хронике — и наказание для зарвавшегося героя, и тюрьма, из которой нужно вытащить союзника, не став её новым узником.
