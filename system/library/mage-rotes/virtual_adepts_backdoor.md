# Чёрный Ход (Backdoor)

- **Принадлежность:** Адепты Виртуальности
- **Сферы:** Связи 2
- **Источник:** Книга Адептов Виртуальности, гл. «Магия»

**Литературное описание.** Адепт скользит по сетям и замкам, находя потайную дверцу там, где её быть не должно: запертая дверь открывается, чужой разговор доносится из трубки, камера показывает пустой коридор. Система просто не замечает гостя.

**Система.** Требуется Связи 2 и подходящее устройство доступа. Каждый успех расширяет охват слежки или обхода: увидеть дальнее место, подслушать комнату, пройти мимо электронной охраны. Хорошо знакомые цели даются легче незнакомых.
