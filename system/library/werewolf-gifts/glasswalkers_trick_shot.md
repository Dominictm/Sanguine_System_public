# Хитрый выстрел (Trick Shot)

- **Группа:** Стеклоходы
- **Уровень:** 1
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** Выбить пулей оружие из рук, попасть в ствол вражеского пистолета — только из ружей и пистолетов и только без прямого урона («стреляю по верёвке над его головой»). Учат духи воздуха.

**Система.** К запасу добавляется постоянная Слава. Прямой урон врагу запрещён; эффект постоянен.
