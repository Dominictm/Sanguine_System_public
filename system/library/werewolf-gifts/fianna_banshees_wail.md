# Вопль баньши (Banshee's Wail)

- **Группа:** Фианна
- **Уровень:** 2
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** Устрашающий вой скорбного духа мёртвых: услышавшие бегут в ужасе. Учит сама Баньши.

**Система.** Пункт Гнозиса + Обаяние + Запугивание. Услышавшие бросают Силу воли (сложность 8, союзникам Фианна — 6) или бегут ход за каждый успех Гару.
