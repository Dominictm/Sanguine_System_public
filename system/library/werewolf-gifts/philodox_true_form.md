# Чутье истинной формы (True Form)

- **Группа:** Филодокс
- **Уровень:** 1
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** Личины не держатся: запах выдаёт истинную природу каждого — оборотня чуют сразу, а для вампира, феи или мага нужен пристальный взгляд.

**Система.** Оборотни опознаются автоматически. Иначе — Восприятие + Первобытный инстинкт: два успеха на вампиров, фей и Фера, четыре — на фоморов и магов.
