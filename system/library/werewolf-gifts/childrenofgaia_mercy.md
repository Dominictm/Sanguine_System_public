# Милосердие (Mercy)

- **Группа:** Дети Гайи
- **Уровень:** 1
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** Дети Гайи видят бесполезность смертоносной силы против всех, кроме слуг Вирма: их клыки и когти бьют, но не убивают — враг падает без чувств и живёт. Учат духи голубя.

**Система.** На сцену весь урон естественным оружием (клыки, когти) считается ударным: жертва без сознания лечится по правилам ударного урона. Ярость может пересилить милосердие.
