# Формат записей Даров (`werewolf-gifts`)

Одна запись = один Дар (не шкала уровней).

```markdown
# Название (English Name)

- **Группа:** хомид | метис | люпус | Рагабаш | Теург | Филодокс | Галлиард | Арун | <племя>
- **Уровень:** 1–5
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** Что происходит в fiction-терминах, своими словами.

**Система.** Пул, стоимость (Гнозис/Ярость/ПСВ) и механика текстом, как в книге.
```

Поля API: `group`, `level`, `description` (литературное), `system`.
Канон защищён (403); авторские — полный CRUD, тело пишется теми же маркерами.
