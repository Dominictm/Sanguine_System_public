# Направленная буря (Direct the Storm)

- **Группа:** Теневые владыки
- **Уровень:** 3
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** Товарищ сорвался в бешенство посреди своих? Владыка разворачивает его ярость на врага по своему выбору — хоть на раба Вирма. Учит Штормовой Ворон.

**Система.** Пункт Гнозиса + Сила воли (сложность равна Ярости цели). Управляет чужим бешенством, направляя на цель; рабом Вирма управлять можно через бросок Ярости (сложность 7) с риском самому впасть в бешенство.
