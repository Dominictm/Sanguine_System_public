# Непроторенная пустошь (Trackless Waste)

- **Группа:** Красные когти
- **Уровень:** 3
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** У людей нет чувства направления — Когти воплощают это в быль: на знакомой местности люди безнадёжно теряются, компасы врут, карты лгут. Учат духи дикой местности.

**Система.** Пункт Гнозиса + Интеллект + Первобытный инстинкт. Радиус — 2 мили за успех, четыре часа; другие оборотни сопротивляются Восприятием + Первобытным инстинктом.
