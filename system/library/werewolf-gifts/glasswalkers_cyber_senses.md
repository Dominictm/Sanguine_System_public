# Киберчувства (Cyber Senses)

- **Группа:** Стеклоходы
- **Уровень:** 2
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** Зачем нос, если есть радар? Зачем глаза, если есть инфракрасный спектр? Стеклоход меняет плоть на сенсоры машин — на сцену. Учит любой технологический дух.

**Система.** Пункт Гнозиса за каждое чувство + Восприятие + Естественные науки. Длится сцену.
