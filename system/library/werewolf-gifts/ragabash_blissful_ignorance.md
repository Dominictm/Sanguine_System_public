# Блаженное неведенье (Blissful Ignorance)

- **Группа:** Рагабаш, Черные фурии, Безмолвные странники
- **Уровень:** 2
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** Оборотень замирает и выпадает из мира чувств: глаза смотрят сквозь него, духи не замечают, приборы молчат. Пока он неподвижен, его словно нет.

**Система.** Игрок бросает Ловкость + Скрытность (сложность 7). Каждый успех снимает один успех с попыток обнаружить Гару; одного успеха довольно, если его не ищут специально.
