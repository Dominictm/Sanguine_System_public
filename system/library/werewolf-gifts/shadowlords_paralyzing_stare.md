# Парализующий взгляд (Paralyzing Stare)

- **Группа:** Теневые владыки
- **Уровень:** 3
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** Пристальный взгляд Владыки пригвождает жертву к месту: она видит его — и не может шевельнуться. Учит Штормовой Ворон.

**Система.** Полный ход концентрации + Обаяние + Запугивание (сложность равна Силе воли жертвы). Цель замирает на ход за успех; должна видеть Гару.
