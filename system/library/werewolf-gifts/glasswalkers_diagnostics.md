# Диагностика (Diagnostics)

- **Группа:** Стеклоходы
- **Уровень:** 1
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** Один взгляд — и причина поломки ясна; с помощью духа устройства Стеклоход чинит механизм силой мысли. Учит любой технологический дух.

**Система.** Восприятие + Ремесла находят поломку. Пункт Гнозиса — мысленное убеждение духа помочь: время ремонта вдвое меньше, успехи Восприятие + Ремесла вычитаются из нужной суммы (см. Ремонт).
