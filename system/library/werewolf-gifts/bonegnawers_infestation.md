# Нашествие (Infestation)

- **Группа:** Костегрызы
- **Уровень:** 4
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** По слову Гару здание кишит паразитами: насекомые, грызуны, слизняки, трупоедные птицы и змеи заползают в тёмные углы и делают дом непригодным для жизни. Учат духи вредителей.

**Система.** Пункт Гнозиса + Манипулирование + Понимание зверей (сложность 7). Один успех разгоняется аэрозолем, пять — кишение по всему дому надолго.
