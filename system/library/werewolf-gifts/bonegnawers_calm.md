# Спокойствие (Calm)

- **Группа:** Костегрызы
- **Уровень:** 2
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** Секрет гашения чужого гнева: слово и взгляд остужают даже готового взорваться. Такому учат духи единорога.

**Система.** Пункт Гнозиса + Обаяние + Эмпатия (сложность равна Силе воли цели). Каждый успех подавляет пункт Ярости (восстанавливается как обычно); у способных к бешенству без Ярости (вампиры, фоморы) гасит бешенство при перевесе над Силой воли.
