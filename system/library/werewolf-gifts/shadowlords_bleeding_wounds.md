# Кровоточащие раны (Bleeding Wounds)

- **Группа:** Теневые владыки
- **Уровень:** 4
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** Нанесённая Владыкой рана не закрывается: кровь течёт и течёт, ослабляя жертву с каждым ходом. Учит дух боли.

**Система.** Пункт Гнозиса + Сила + Медицина (сложность 7). Если следующая атака ранит — цель теряет уровень здоровья (летальный) в ход, ходов по числу успехов.
