# Перехват преимущества (Seizing the Edge)

- **Группа:** Теневые владыки
- **Уровень:** 1
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** Для Владыки ничьих не бывает: где весы качнулись поровну — там победа его. Хоть Фенрира на лопатки положить. Учат духи Деда Грома.

**Система.** Пункт Гнозиса на сцену: ничья во встречном броске с участием Владыки трактуется в его пользу.
