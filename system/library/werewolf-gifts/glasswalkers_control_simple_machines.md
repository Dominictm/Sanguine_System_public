# Контроль простых устройств (Control Simple Machines)

- **Группа:** Стеклоходы
- **Уровень:** 1
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** Духи простых механизмов слушаются голоса: засовы сдвигаются, двери открываются сами. Любому технологическому духу по силам научить этому.

**Система.** Пункт Силы воли + Манипулирование + Ремесла (сложность 7). Контроль длится сцену.
