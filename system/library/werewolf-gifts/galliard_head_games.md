# Игры разума (Head Games)

- **Группа:** Галлиард
- **Уровень:** 5
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** Чистая власть над чувствами: любовь сменяется ненавистью по воле сказителя, страх — обожанием. Внушённое держится, лишь пока его подпитывают делами, — иначе перерастает в заслуженную вражду.

**Система.** Манипулирование + Эмпатия (сложность равна Силе воли жертвы). Чем больше успехов, тем резче и сильнее перелом чувств.
