# Отвлечение (Distractions)

- **Группа:** Галлиард
- **Уровень:** 2
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** Визг, выкрики и завывания врываются в чужую сосредоточенность: враг дёргается, теряет нить и пропускает удар. Духи койота — первые мастера таких шуток.

**Система.** Сообразительность + Исполнение (сложность равна Силе воли жертвы). Каждый успех снимает кубик из запаса цели на следующий ход.
