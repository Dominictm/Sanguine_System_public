# Создать стихию (Create Element)

- **Группа:** метис
- **Уровень:** 1
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** Метис просит духов стихий поделиться малой частицей их сути: в ладонях вспыхивает огонёк, в закупоренной комнате появляется глоток воздуха, из сухой земли проступает вода. Стихия настоящая, но небольшая — ровно столько, сколько нужно для дела.

**Система.** Игрок тратит пункт Гнозиса и бросает Гнозис (сложность 7). Каждый успех создаёт около кубического фута естественной стихии (огонь, воздух, земля, вода) в пределах видимости. Созданное сохраняется, пока не израсходуется.
