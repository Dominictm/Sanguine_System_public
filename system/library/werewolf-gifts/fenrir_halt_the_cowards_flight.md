# Задержка бегущего труса (Halt the Coward's Flight)

- **Группа:** Потомки Фенрира
- **Уровень:** 2
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** Убегающего — но не сражающегося — врага можно замедлить, чтобы взять его тёплым. Учат духи волка.

**Система.** Полный ход концентрации, затем Обаяние + Запугивание (сложность равна Силе воли жертвы). Скорость цели падает вдвое на сцену.
