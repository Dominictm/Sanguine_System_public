# Завершающий удар (Coup de Grace)

- **Группа:** Черные фурии
- **Уровень:** 3
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** Фурия изучает врага, высматривая место для единственного смертоносного удара, — и бьёт туда, где кончается жизнь. Выслеживать так учит дух совы.

**Система.** Пункт Силы воли + Восприятие + Рукопашный бой (сложность равна Выносливость + Уклонение цели). Успех удваивает запас кубиков урона следующей атаки по этой цели.
