# Приказ духу (Command Spirit)

- **Группа:** Теург
- **Уровень:** 2
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** Властный голос, которому духи повинуются: один простой приказ — и дух исполняет его, а затем уходит. Вызывать духов этим Даром нельзя, только повелевать встреченными.

**Система.** Игрок тратит пункт Силы воли и бросает Обаяние + Лидерство (сложность равна Гнозису духа). Каждая новая команда — ещё пункт Силы воли. Выгнать духа с его места этим Даром нельзя.
