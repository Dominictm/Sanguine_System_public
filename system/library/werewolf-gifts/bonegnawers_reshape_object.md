# Видоизменить объект (Reshape Object)

- **Группа:** Костегрызы, Фианна, хомид
- **Уровень:** 3
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** Живой материал слушается рук оборотня: бревно становится частоколом, рог — копьём, шкура — бронёй, а цветы — благовониями. Вещь наследует свойства материала, из которого рождена. Учит Узорный паук, дух Вивер.

**Система.** Игрок тратит пункт Гнозиса и бросает Манипулирование + Ремесла (сложность 5 для копья из ветки, 8 для плота из досок). Длительность по успехам: 1 — 5 минут, 2 — 10 минут, 3 — сцена, 4 — история, 5 — навсегда. Лишний пункт Гнозиса даёт оружию аггравированный урон до конца сцены; трата постоянного Гнозиса делает изменение необратимым.
