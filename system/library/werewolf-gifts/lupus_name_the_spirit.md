# Имена духов (Name the Spirit)

- **Группа:** люпус
- **Уровень:** 3
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** Тропы Умбры открываются знающему: оборотень чует породу встречного духа и меру его черт — Ярости, Гнозиса, Силы воли. Преподают духи тотема Уктены.

**Система.** Игрок тратит пункт Силы воли и бросает Восприятие + Оккультизм (сложность 8), чтобы распознать тип и уровень черт духа.
