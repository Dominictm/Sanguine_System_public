# Великий прыжок (Great Leap)

- **Группа:** Безмолвные странники
- **Уровень:** 3
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** Прыжок на поразительное расстояние — на тридцать метров за успех. Учат духи прерийного зайца.

**Система.** Пункт Силы воли + Сила + Атлетика. По 30 метров за успех.
