# Телесное разорение (Body Wrack)

- **Группа:** Черные фурии
- **Уровень:** 4
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** Достаточно указать на цель — и её тело пронзает чрезмерная, травмирующая боль духа боли: мышцы сводит, дыхание рвётся, броски разваливаются.

**Система.** Пункт Гнозиса + Сила + Медицина (сложность равна Выносливость противника + 3). Каждый успех снимает кубик со всех бросков жертвы на сцену.
