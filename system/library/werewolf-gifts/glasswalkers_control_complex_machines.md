# Контроль сложных устройств (Control Complex Machines)

- **Группа:** Стеклоходы
- **Уровень:** 3
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** Компьютеры, автомобили, игровые приставки — духи электронных устройств повинуются голосу. Тайну знают только Сетевые пауки — у них и крадут.

**Система.** Пункт Силы воли + Манипулирование + Естественные науки (или Компьютеры), сложность по машине (обычно 8). Контроль на сцену.
