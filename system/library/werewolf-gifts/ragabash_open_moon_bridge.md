# Открыть Лунный мост (Open Moon Bridge)

- **Группа:** Рагабаш
- **Уровень:** 3
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** Оборотень распахивает светящийся мост между каэрнами — дорогу лунного света, по которой стая идёт сквозь Умбру за считанные мгновения. Так ходят те, кому доверяет тотем.

**Система.** Игрок тратит пункт Гнозиса. Дальность — не более 1000 миль; подробности — в обряде открытия моста.
