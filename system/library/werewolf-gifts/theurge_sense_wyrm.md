# Чутье Вирма (Sense Wyrm)

- **Группа:** Теург, Черные фурии, Безмолвные странники, метис
- **Уровень:** 1
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** Порча Вирма имеет свой запах — не для носа, а для внутреннего чутья: оборотень ощущает её присутствие в округе, даже если носитель выглядит невинно. Дар требует сосредоточенности, а учат ему любые духи Гайи.

**Система.** Игрок бросает Восприятие + Оккультизм; сложность зависит от силы и давности скверны (фомор за стеной — 6, след Бэйна, бывшего здесь несколько часов назад, — 8). Вампиры чуются отродьями Вирма, если их Человечность ниже 7.
