# Адаптация (Adaptation)

- **Группа:** Безмолвные странники
- **Уровень:** 3
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** Ни болезни, ни яды, ни давление, ни жара, ни холод — странник существует везде, кроме прямой опасности вроде падения. Учат духи медведя.

**Система.** Пункт Гнозиса + Выносливость + Выживание (сложность 7). Час за успех.
