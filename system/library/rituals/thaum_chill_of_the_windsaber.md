# 🕯️ Холод Клинка Ветра (Chill of the Windsaber)

- **Традиция:** thaumaturgy
- **Уровень:** 7
- **Источник:** Player's Guide to the Sabbat, стр. 122 (не сверено)

**Литературное описание.** Сложенное стекло превращается в незримый клинок, который по жесту колдуна срубает голову.

**Система.** Восприятие + Огнестрельное оружие (сложность 8); увернуться — Ловкость + Эмпатия (сложность 9). Смертельно для большинства существ.
