# 🕯️ Зашифровать Послание (Encrypt Missive)

- **Традиция:** thaumaturgy
- **Уровень:** 1
- **Источник:** Blood Magic: Secrets of Thaumaturgy, стр. 87 (не сверено)

**Литературное описание.** Письмо пишут кровью, называя вслух имя адресата, — и для всех остальных строки превращаются в бессмыслицу.

**Система.** Прочитать письмо могут только автор и названный получатель; для прочих текст выглядит тарабарщиной. Снять защиту позволяют отдельные контр-ритуалы.
