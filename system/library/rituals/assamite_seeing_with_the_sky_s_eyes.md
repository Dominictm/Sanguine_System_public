# 🗡️ Глазами Неба (Seeing with the Sky's Eyes)

- **Традиция:** assamite
- **Уровень:** 5
- **Источник:** Blood Magic: Secrets of Thaumaturgy, стр. 126 (не сверено)

**Литературное описание.** В трансе по изображению или вещи колдун находит цель где угодно на Земле.

**Система.** Визири нередко продают эту услугу младшим ассамитам, выслеживающим цели контрактов.
