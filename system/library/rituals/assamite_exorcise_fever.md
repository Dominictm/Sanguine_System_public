# 🗡️ Изгнать Лихорадку (Exorcise Fever)

- **Традиция:** assamite
- **Уровень:** 1
- **Источник:** Blood Sacrifice: The Thaumaturgy Companion, стр. 47 (не сверено)

**Литературное описание.** Колдун изгоняет из больного духов лихорадки.

**Система.** Один успех излечивает лёгкую лихорадочную болезнь, два-три — смертельно опасную.
