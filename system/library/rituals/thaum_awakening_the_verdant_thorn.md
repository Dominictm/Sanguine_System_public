# 🕯️ Пробуждение Зелёного Шипа (Awakening the Verdant Thorn)

- **Традиция:** thaumaturgy
- **Уровень:** 3
- **Источник:** Player's Guide to the Low Clans, стр. 170 (не сверено)

**Литературное описание.** В кол из розового дерева заключают мстительного лесного духа; вонзённый в вампира, кол пускает корни и тянет из него кровь.

**Система.** Час подготовки: кол закаляют в огне, колдун пронзает им себе сердце (1 уровень летального урона). В жертве кол вытягивает по пункту крови за ход; чтобы извлечь его, нужно побороть накопленную им кровь (не более 8).
