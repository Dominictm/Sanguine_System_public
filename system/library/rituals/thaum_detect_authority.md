# 🕯️ Распознать Власть (Detect Authority)

- **Традиция:** thaumaturgy
- **Уровень:** 2
- **Источник:** Anarch Cookbook, стр. 61 (не сверено)

**Литературное описание.** Анархская проверка новичков: через обмен кровью колдун чувствует, не связан ли собеседник узами или волей Князя.

**Система.** Бросок Восприятия + Запугивания; одного успеха достаточно, чтобы выявить узы крови или подчинение. Для птенцов процедура опасна.
