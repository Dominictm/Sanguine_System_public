# 🌋 Стражи Убежища (Sentinels of the Haven)

- **Традиция:** koldun
- **Уровень:** 3
- **Источник:** Player's Guide to the High Clans, стр. 192 (не сверено)

**Литературное описание.** Предметы в убежище оживают и слегка слушаются духов.

**Система.** Двигаться может только один предмет за раз; черты духов определяет Рассказчик.
