# 💀 Божественный Знак (Divine Sign)

- **Традиция:** necromancy
- **Уровень:** 3
- **Источник:** Clanbook: Giovanni (Revised), стр. 72 (не сверено)

**Литературное описание.** Ацтекская астрология Писанобов: некромант узнаёт знак дня, под которым родился человек.

**Система.** Позволяет предугадывать поступки живого или связаться с призраком так, будто у него есть привязь.
