# 🕯️ Камень Истинного Облика (Stone of the True Form)

- **Традиция:** thaumaturgy
- **Уровень:** 5
- **Источник:** Blood Magic: Secrets of Thaumaturgy, стр. 98 (не сверено)

**Литературное описание.** Камешек, покрытый витэ, срывает с существа чужой облик и возвращает истинный.

**Система.** 1 пункт витэ. При касании — встречный бросок Силы Воли (сложность = Выносливость другой стороны); при успехе изменённая форма спадает.
