# Библиотека ритуалов

Канонический источник справочника ритуалов: **по одному MD-файлу на ритуал**.
Сервер (`web/lib/rituals.js` → `parseRitualMd`) парсит эти файлы и отдаёт их по
`GET /api/library/rituals`; веб рендерит вкладку «Библиотека → Ритуалы» и подбор
ритуала в листе V20. Спека — `doc/design/2026-09-24-library-rituals-spec.md`.

## Формат файла

```markdown
# 🕯️ Защита Священного Убежища (Defense of the Sacred Haven)

- **Традиция:** thaumaturgy
- **Уровень:** 1
- **Источник:** V20, стр. 226

**Литературное описание.** <что это за обряд и как он выглядит — своими словами>

**Система.** <механика: стоимость, бросок, сложность, эффект — своими словами>
```

- **Имя файла (слаг):** `<префикс традиции>_<английское название>`, латиница `[a-z0-9_]`:
  `thaum_…`, `necro_…`, `assamite_…`, `koldun_…`, `osiris_…`.
- **Традиция** — код из списка:

  | Код | Традиция | Уровни | Дисциплина в Библиотеке |
  |---|---|---|---|
  | `thaumaturgy` | Тауматургия | 1–10 | `disciplines/thaumaturgy.md` |
  | `necromancy` | Некромантия | 1–5 | `disciplines/necromancy.md` |
  | `assamite` | Ассамитское колдовство | 1–7 | `disciplines/assamite-sorcery.md` |
  | `koldun` | Колдунство | 1–9 | `disciplines/koldun.md` |
  | `osiris` | Дети Осириса | 10 | — |

- **Источник** — книга и страница. Страница сверена по книге → `Книга, стр. N`.
  Не сверена (книги нет в `F:\GitHUbe\bock\` или нет текстового слоя) →
  `Книга, стр. N (не сверено)` — веб покажет метку «⚠ не сверено».
  Неверная страница хуже отсутствующей: при сомнении — только книга.
- **Авторская запись** (создана из веба) — дополнительно `- **Авторское:** да`;
  канонические записи из веба не правятся и не удаляются.
- Тексты — **пересказ своими словами** (правило проекта «Лицензия» в `CLAUDE.md`),
  не копия книги или перевода.
