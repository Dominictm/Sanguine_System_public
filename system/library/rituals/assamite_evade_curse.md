# 🗡️ Уклониться от Проклятия (Evade Curse)

- **Традиция:** assamite
- **Уровень:** 6
- **Источник:** Clanbook: Assamite, стр. 28 (не сверено)

**Литературное описание.** На время ассамит может пить кровь Сородичей, несмотря на проклятие клана.

**Система.** Столько ходов, сколько успехов; помеченная кровь тратится первой, остаток по окончании наносит губительный урон. Устарел после снятия проклятия.
