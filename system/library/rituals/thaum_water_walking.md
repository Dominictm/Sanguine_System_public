# 🕯️ Хождение по Воде (Water Walking)

- **Традиция:** thaumaturgy
- **Уровень:** 1
- **Источник:** Blood Sacrifice: The Thaumaturgy Companion, стр. 65 (не сверено)

**Литературное описание.** Жертва Варуне — овёс и топлёное масло — позволяет пройти по воде, как по земле.

**Система.** Одну сцену колдун ходит по поверхности воды; если его сбивают с ног, он проваливается в воду. Доступно только колдунам индийской традиции.
