# 🕯️ Неутолимая Жажда (Thirst Unquenchable)

- **Традиция:** thaumaturgy
- **Уровень:** 5
- **Источник:** Player's Guide to the Sabbat, стр. 121 (не сверено)

**Литературное описание.** Горсть соли — и другой вампир не может утолить голод.

**Система.** До конца ночи жертва получает лишь половину выпитой витэ, а сложность сопротивления неистовству растёт на 2.
