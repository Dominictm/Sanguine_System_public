# 🕯️ Горящий Клинок (Burning Blade)

- **Традиция:** thaumaturgy
- **Уровень:** 2
- **Источник:** Guide to the Camarilla, стр. 110 (не сверено)

**Литературное описание.** Клинок окутывает бледно-зелёное пламя, и нанесённые им раны сверхъестественные существа не могут залечить обычным образом.

**Система.** 3 пункта крови, только холодное оружие. Число успехов — число атак, наносящих губительный (аггравированный) урон.
