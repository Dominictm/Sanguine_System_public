# 🕯️ Кровяной Фиал (Sanguineous Phial)

- **Традиция:** thaumaturgy
- **Уровень:** 1
- **Источник:** Blood Magic: Secrets of Thaumaturgy, стр. 90 (не сверено)

**Литературное описание.** Средневековый способ хранения: глиняный сосуд две ночи лежит в земле, затем его наполняют кровью с листом ясеня и запечатывают салом.

**Система.** Кровь остаётся свежей, пока сосуд не открыт; если он разбит, кровь портится мгновенно. Для повторного использования ритуал проводят заново.
