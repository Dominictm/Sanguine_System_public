# 🌋 Отражения (Reflections)

- **Традиция:** koldun
- **Уровень:** 1
- **Источник:** Blood Sacrifice: The Thaumaturgy Companion, стр. 85 (не сверено)

**Литературное описание.** Через предмет, взятый из места, колдун астрально переносится туда и видит его таким, каким оно было, когда предмет забрали.

**Система.** Длительность в ходах — успехи плюс Сила Воли.
