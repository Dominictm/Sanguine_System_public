# 🕯️ Гнилое Дерево (Rotten Wood)

- **Традиция:** thaumaturgy
- **Уровень:** 3
- **Источник:** Player's Guide to the Sabbat, стр. 118 (не сверено)

**Литературное описание.** Заранее проведённый обряд и слово команды — и деревянное оружие, направленное на колдуна, рассыпается в труху.

**Система.** Действует одну ночь и срабатывает по слову команды.
