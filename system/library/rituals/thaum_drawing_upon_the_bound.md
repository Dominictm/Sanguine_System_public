# 🕯️ Черпать из Связанного (Drawing upon the Bound)

- **Традиция:** thaumaturgy
- **Уровень:** 4
- **Источник:** Player's Guide to the Sabbat, стр. 119 (не сверено)

**Литературное описание.** Колдун пользуется дисциплинами того, кто связан с ним узами крови, — обычно гуля.

**Система.** Нужен флакон крови связанного; работает только при прямых узах. Пока колдун черпает его силы, связанный сам ими пользоваться не может.
