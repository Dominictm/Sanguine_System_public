# 🌋 Изгнать Лелека (Raze the Lelek)

- **Традиция:** koldun
- **Уровень:** 3
- **Источник:** Sins of the Blood, стр. 99 (не сверено)

**Литературное описание.** Разлучив предмет с его духом, колдун разрушает его.

**Система.** Размер предмета — по успехам: для ручки хватит одного, для машины нужно пять.
