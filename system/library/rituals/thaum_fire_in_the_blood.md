# 🕯️ Огонь в Крови (Fire in the Blood)

- **Традиция:** thaumaturgy
- **Уровень:** 3
- **Источник:** Player's Guide to the Sabbat, стр. 118 (не сверено)

**Литературное описание.** Кровь жертвы раскаляется: любое усилие отзывается жгучей раной изнутри.

**Система.** Без компонентов. При каждом броске физической характеристики жертва получает уровень губительного урона, пока не преуспеет в броске Смекалки + Медицины (сложность 7).
