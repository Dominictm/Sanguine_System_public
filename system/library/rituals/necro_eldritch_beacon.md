# 💀 Потусторонний Маяк (Eldritch Beacon)

- **Традиция:** necromancy
- **Уровень:** 1
- **Источник:** Guide to the Sabbat, стр. 110 (не сверено)

**Литературное описание.** Восковая сфера делает своего носителя видимым и притягательным для призраков в Землях Теней.

**Система.** 15 минут; действует час за успех. Силы призраков против носителя действуют эффективнее.
