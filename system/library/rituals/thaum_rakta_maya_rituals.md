# 🕯️ Обряды Ракта-Майи (Rakta-Maya Rituals)

- **Традиция:** thaumaturgy
- **Уровень:** 1
- **Источник:** Blood Sacrifice: The Thaumaturgy Companion, стр. 64 (не сверено)

**Литературное описание.** Набор иллюзорных чудес индийских колдунов: верёвка, по которой взбираются в небо, полёт, исчезновения — зрители видят их все вместе.

**Система.** Бросок Харизмы + Исполнения (сложность 4); действует на десятки зрителей в очерченной границе. Создаёт общую иллюзию. Доступно только колдунам индийской традиции.
