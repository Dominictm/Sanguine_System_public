# 🕯️ Распустить Ритуал (Unweave Ritual)

- **Традиция:** thaumaturgy
- **Уровень:** 4
- **Источник:** Clanbook: Tremere (Revised), стр. 64 (не сверено)

**Литературное описание.** Колдун находит компонент чужого действующего ритуала и уничтожает его, распуская чары.

**Система.** Знакомый ритуал распознаётся сразу, иначе — Интеллект + Оккультизм. Успехи вычитаются из успехов исходного ритуала; при полном обнулении эффект заканчивается. Только для длительных ритуалов, действующих на самого колдуна.
