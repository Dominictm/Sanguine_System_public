# 🕯️ Откровение Кровной Линии (Revelation of the Blood Lineage)

- **Традиция:** thaumaturgy
- **Уровень:** 2
- **Источник:** Dark Ages: Vampire, стр. 218 (не сверено)

**Литературное описание.** Средневековый предшественник Пути по Крови: по крови вампира колдун видит его предков.

**Система.** Три часа (−15 минут за успех), 1 пункт крови объекта; каждый успех открывает поколение предков.
