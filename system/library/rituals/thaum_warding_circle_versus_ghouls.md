# 🕯️ Охранный Круг против Гулей (Warding Circle versus Ghouls)

- **Традиция:** thaumaturgy
- **Уровень:** 2
- **Источник:** Guide to the Camarilla, стр. 111 (не сверено)

**Литературное описание.** Круг, начерченный кровью смертных, не пускает гулей внутрь.

**Система.** 3 пункта крови смертного на круг радиусом около 3 метров, плюс пункт за каждые следующие 3 метра. Гуль, пытающийся войти, бросает против сложности 8 и получает 3 кости ударного урона.
