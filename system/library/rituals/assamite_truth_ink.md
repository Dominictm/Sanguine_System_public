# 🗡️ Чернила Истины (Truth Ink)

- **Традиция:** assamite
- **Уровень:** 1
- **Источник:** Caine's Chosen: The Black Hand, стр. 77 (не сверено)

**Литературное описание.** Колдун мгновенно узнаёт, нанесена ли татуировка-полумесяц по настоящему обряду Чёрной Руки.

**Система.** Дополнительные успехи дают видения обстоятельств, при которых метку нанесли.
