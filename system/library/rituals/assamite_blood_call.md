# 🗡️ Зов Крови (Blood Call)

- **Традиция:** assamite
- **Уровень:** 2
- **Источник:** Clanbook: Assamite, стр. 28 (не сверено)

**Литературное описание.** Духовная связь двух участников: один узнает об Окончательной Смерти другого и увидит, как это было.

**Система.** Час работы, по 2 пункта крови с каждого участника.
