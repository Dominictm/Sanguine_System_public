# 💀 Обряд Почтли (The Ritual of Pochtli)

- **Традиция:** necromancy
- **Уровень:** 2
- **Источник:** Clanbook: Giovanni (Revised), стр. 44 (не сверено)

**Литературное описание.** Несколько некромантов объединяют силы для совместного обряда.

**Система.** Успехи участников при совместном ритуале или применении пути складываются; один провал обнуляет все.
