# 🕯️ Потусторонний Отблеск (Eldritch Glimmer)

- **Традиция:** thaumaturgy
- **Уровень:** 3
- **Источник:** Player's Guide to the Sabbat, стр. 118 (не сверено)

**Литературное описание.** Колдуна окутывает бледно-зелёное свечение, из которого он мечет разряды энергии.

**Система.** Нужен песчаник, вымоченный в уксусе. Каждый разряд стоит 1 пункт крови; попадание — Восприятие + Огнестрельное оружие (сложность 6), урон 3 кости.
