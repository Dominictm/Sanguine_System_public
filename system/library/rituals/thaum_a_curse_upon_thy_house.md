# 🕯️ Проклятие на Твой Дом (A Curse Upon Thy House)

- **Традиция:** thaumaturgy
- **Уровень:** 5
- **Источник:** Anarch Cookbook, стр. 78 (не сверено)

**Литературное описание.** Проклятие ложится на всех потомков жертвы, пока её вина не будет искуплена.

**Система.** Манипуляция + Запугивание (сложность 8), по успеху на каждую жертву; за каждую колдун теряет пункт постоянной Силы Воли.
