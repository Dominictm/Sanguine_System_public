# 🕯️ Погасить (Extinguish)

- **Традиция:** thaumaturgy
- **Уровень:** 2
- **Источник:** Blood Magic: Secrets of Thaumaturgy, стр. 92 (не сверено)

**Литературное описание.** Одно произнесённое слово — и пламя размером до костра гаснет.

**Система.** Слог можно применить столько раз за ночь, сколько получено успехов. Сама работа с огнём может спровоцировать Ротшрек.
