# 🕯️ Дом с Привидениями (Haunted House)

- **Традиция:** thaumaturgy
- **Уровень:** 3
- **Источник:** Milwaukee by Night, стр. 54 (не сверено)

**Литературное описание.** Жилище получает дурную славу, и смертные обходят его стороной.

**Система.** Три часа, 3+ пункта крови. Около десяти лет дом считается «нехорошим», потом — просто заброшенным. Тремеры долго запрещали этот обряд.
