# 🕯️ Путь по Крови (Blood Walk)

- **Традиция:** thaumaturgy
- **Уровень:** 2
- **Источник:** Guide to the Camarilla, стр. 110 (не сверено)

**Литературное описание.** По образцу крови колдун проходит назад по линии Становления и видит сиров вампира и его узы.

**Система.** Три часа (−15 минут за успех) и 1 пункт крови объекта. Каждый успех открывает поколение предков; также видны узы крови, в которых состоит объект.
