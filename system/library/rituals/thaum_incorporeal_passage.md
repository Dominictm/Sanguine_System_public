# 🕯️ Бесплотный Проход (Incorporeal Passage)

- **Традиция:** thaumaturgy
- **Уровень:** 3
- **Источник:** Vampire: The Masquerade (Revised), стр. 184 (не сверено)

**Литературное описание.** Держа осколок разбитого зеркала, колдун становится бесплотным и проходит сквозь стены.

**Система.** Бросок Смекалки + Выживания (сложность 6): длительность в часах по успехам. Двигаться можно только по прямой, в ту сторону, куда смотрит отражение.
