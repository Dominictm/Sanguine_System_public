# 🗡️ Погибель Кафира (Kafir's Bane)

- **Традиция:** assamite
- **Уровень:** 3
- **Источник:** Sins of the Blood, стр. 102 (не сверено)

**Литературное описание.** Перед боем ассамит седлает своего Зверя.

**Система.** В одной схватке колдун автоматически управляет неистовством; если до рассвета неистовства не было, обряд пропадает.
