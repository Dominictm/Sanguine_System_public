# 🕯️ Отсечённая Рука (Severed Hand)

- **Традиция:** thaumaturgy
- **Уровень:** 5
- **Источник:** Blood Magic: Secrets of Thaumaturgy, стр. 98 (не сверено)

**Литературное описание.** Алхимическая обработка раны не даёт отсечённой конечности отрасти.

**Система.** Целая ночь работы. Утраченная часть не регенерирует без магического исцеления (например, Обеа).
