# 🕯️ Оберег от Люпинов (Ward versus Lupines)

- **Традиция:** thaumaturgy
- **Уровень:** 3
- **Источник:** Guide to the Camarilla, стр. 113 (не сверено)

**Литературное описание.** Серебряный порошок создаёт барьер, болезненно отталкивающий оборотней.

**Система.** Горсть серебряного порошка. Гару, пересекающий оберег, получает 3 уровня летального урона за ход; на других оборотней не действует.
