# 💀 Хватка Призрачного (Grasp the Ghostly)

- **Традиция:** necromancy
- **Уровень:** 5
- **Источник:** Vampire: The Masquerade (Revised), стр. 165 (не сверено)

**Литературное описание.** Предмет из Земель Теней переносится в мир живых в обмен на вещь сходной массы.

**Система.** Шесть часов. Перенесённый предмет обычно разрушается примерно через год.
