# 💀 Марионетка (Puppet)

- **Традиция:** necromancy
- **Уровень:** 2
- **Источник:** Guide to the Sabbat, стр. 110 (не сверено)

**Литературное описание.** Глаза, губы и лоб цели умащают кладбищенской землёй, открывая её для одержимости.

**Система.** Час работы. Всю ночь призрак, пытающийся вселиться в цель, получает 2 автоматических успеха.
