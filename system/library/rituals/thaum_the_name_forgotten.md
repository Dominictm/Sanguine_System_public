# 🕯️ Забытое Имя (The Name Forgotten)

- **Традиция:** thaumaturgy
- **Уровень:** 8
- **Источник:** Transylvania Chronicles III, стр. 42 (не сверено)

**Литературное описание.** После Окончательной Смерти колдуна его имя исчезает из всех памятей и записей.

**Система.** Сто лет; имя пишут кровью сира, каждый год тратится пункт Силы Воли. Необратимо, противоядие неизвестно.
