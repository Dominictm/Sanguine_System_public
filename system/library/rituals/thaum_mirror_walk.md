# 🕯️ Сквозь Зеркало (Mirror Walk)

- **Традиция:** thaumaturgy
- **Уровень:** 4
- **Источник:** Player's Guide to the Sabbat, стр. 120 (не сверено)

**Литературное описание.** Зеркало становится жидким, и колдун проходит сквозь него, выходя из ближайшей достаточно большой отражающей поверхности.

**Система.** Изумрудное кольцо светится во время обряда; одного спутника можно провести, держа за руку. Постороннему, коснувшемуся зеркала, пока идёт рябь, нужен бросок Ловкости + Уклонения (сложность 7), иначе его рассечёт между двумя зеркалами.
