# 🕯️ Сохранить Кровь (Preserve Blood)

- **Традиция:** thaumaturgy
- **Уровень:** 1
- **Источник:** Player's Guide to the Sabbat, стр. 117 (не сверено)

**Литературное описание.** Вариант обряда с липовым листом и салом: запечатанная кровь не портится сколь угодно долго.

**Система.** Кровь в запечатанном сосуде остаётся свежей, пока печать цела. Сосуд можно использовать повторно, проведя ритуал заново.
