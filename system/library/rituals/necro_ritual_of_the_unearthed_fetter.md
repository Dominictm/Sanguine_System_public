# 💀 Обряд Выкопанной Привязи (Ritual of the Unearthed Fetter)

- **Традиция:** necromancy
- **Уровень:** 3
- **Источник:** Vampire: The Masquerade (Revised), стр. 165 (не сверено)

**Литературное описание.** Из фаланги пальца призрака и пыли кладбищенского камня создают для него новую привязь.

**Система.** Три часа. Созданная привязь облегчает некромантию против этого призрака.
