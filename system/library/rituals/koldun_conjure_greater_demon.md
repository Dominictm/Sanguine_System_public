# 🌋 Вызов Великого Демона (Conjure Greater Demon)

- **Традиция:** koldun
- **Уровень:** 5
- **Источник:** Libellus Sanguinis 1: Masters of the State, стр. 63 (не сверено)

**Литературное описание.** По истинному имени колдун призывает могущественного славянского демона.

**Система.** Подчинить его труднее, чем малого беса; силы демона задаёт Рассказчик.
