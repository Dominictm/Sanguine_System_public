# 🗡️ Целительная Кровь (Healing Blood)

- **Традиция:** assamite
- **Уровень:** 7
- **Источник:** Clanbook: Assamite, стр. 28 (не сверено)

**Литературное описание.** После десятиминутной медитации кровь напрямую заживляет губительные раны.

**Система.** 1 пункт крови за уровень губительного урона; без траты Силы Воли и без ограничения числа применений за ночь.
