# 🕯️ Блуждающий Огонёк (Will o' the Wisp)

- **Традиция:** thaumaturgy
- **Уровень:** 1
- **Источник:** Player's Guide to the Sabbat, стр. 117 (не сверено)

**Литературное описание.** Подброшенная ивовая ветка вспыхивает шаром света, который послушно движется по мысленной команде колдуна.

**Система.** Пока колдун сосредоточен, шар остаётся в пределах его видимости и выполняет простые команды: разгорается, тускнеет, делится, облетает предметы.
