# 🕯️ Сбросить Оковы (Abandon the Fetters)

- **Традиция:** thaumaturgy
- **Уровень:** 5
- **Источник:** Clanbook: Tremere (Revised), стр. 65 (не сверено)

**Литературное описание.** Мучительный обряд обескровливания и сдирания кожи разрывает узы крови.

**Система.** Целая ночь; нужна кровь трёх сторон. Связанный получает 3 уровня губительного урона, которые нельзя поглотить, обе стороны уз — ещё по 1; колдун теряет пункт постоянной Силы Воли. Узы разрываются.
