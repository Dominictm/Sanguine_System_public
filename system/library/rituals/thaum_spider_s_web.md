# 🕯️ Паутина (Spider's Web)

- **Традиция:** thaumaturgy
- **Уровень:** 6
- **Источник:** Player's Guide to the Sabbat, стр. 122 (не сверено)

**Литературное описание.** Проглотив чёрную вдову, колдун заполняет комнату гигантской липкой паутиной.

**Система.** Увернуться — Ловкость + Уклонение; выбраться — Сила (сложность 6), нужно 3+ успеха.
