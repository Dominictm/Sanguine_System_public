# 🕯️ Цертамен (Certamen)

- **Традиция:** thaumaturgy
- **Уровень:** 3
- **Источник:** Player's Guide to the Low Clans, стр. 172 (не сверено)

**Литературное описание.** Ритуальная дуэль герметических магов: два кровавых круга, зримые вспышки усиленных заклинаний.

**Система.** Участники вкладывают витэ, равную своему Оккультизму, чтобы снизить сложность своих чар в поединке. Дуэль идёт до сдачи или смерти.
