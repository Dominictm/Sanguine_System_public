# Костяные Ритмы (Bone Rhythms)

- **Тип:** малый
- **Уровень:** 1
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** Каждому духу тотема — свой ритм на костяных палочках: три дня подряд, и Умбра отвечает лишним кубиком на любой бросок. Потом — три дня перенастройки.

**Система.** Исполнить три дня подряд: трижды по одному бонусному кубику на любой бросок в Умбре; затем три дня перенастройки для нового цикла.
