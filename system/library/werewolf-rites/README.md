# Формат записей обрядов (`werewolf-rites`)

Без числовых уровней (в книге уровней нет).

```markdown
# Название (English Name)

- **Тип:** гармонии | каэрна | смерти | мистический | наказаний | свершений | известности | сезонный | малый
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

## Описание

Текст обряда своими словами.

**Система.** Механика текстом (если есть в книге).
```

Поля API: `type`, `description`, `system`.
