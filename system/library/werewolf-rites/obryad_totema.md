# Обряд тотема (Rite of the Totem)

- **Тип:** мистический
- **Уровень:** 3
- **Источник:** Оборотни: Апокалипсис (Revised), гл. 4

**Литературное описание.** Обряд вяжет желающих в стаю узами общего тотема, сплавляя их судьбы в одну. Соискатели мажут глаза смесью слюны с полынью, табаком или иной святыней Гайи и делают Шаг за грань, а мастер ведёт их по Умбре охотой по мистическому следу духа — у каждого тотема след свой. Достойных тотем обычно принимает, но вправе и испытать соискателей, задав им поручение, хотя после славного Перехода заданий почти не бывает.

**Система.** Без приобретённого Дополнения Тотем обряд просто не состоится; бросок — стандартный для мистического обряда.
