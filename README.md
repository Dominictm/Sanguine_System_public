Локальный менеджер хроник для **Vampire: The Masquerade V20** (и смежных линеек WoD).
Инструмент Рассказчика: персонажи, хроники, модули, локации, политика — всё в одном месте.
ИИ-генерация прозы, реплик НПС, сценариев и листов V20 через Claude / Gemini / GPT / OpenRouter.

> 📖 **Полное руководство** — [docs/guide.md](docs/guide.md)

## Быстрый старт

```
Двойной клик → start.bat
```

Браузер откроется на `http://localhost:4295`. Node.js и Git установятся автоматически при первом запуске.

**Системные требования:** Windows 10+ x64, современный браузер.

Всё хранится локально, в обычных Markdown-файлах — никакой базы данных, аккаунтов и облака. Интерфейс **работает без интернета**: шрифты и библиотека графа лежат внутри проекта, внешних CDN нет. Сеть нужна только для ИИ-генерации и обновлений.

## Возможности

| Раздел | Что делает |
|--------|------------|
| **Панель** | Статистика города, открытые нити, активность |
| **Хронология** | Таймлайн событий с фильтрами по хроникам |
| **Персонажи** | Карточки, биографии, дневники, листы V20, реплики |
| **Связи** | Интерактивный граф отношений (D3.js) с фильтрами по линейке и виду связи; словарь видов — свой у каждого города, правится из интерфейса и руками |
| **Фракции** | Политическая карта: альянсы, вражда, нейтралитет |
| **Локации** | Атмосфера, VtM-контекст, крючки |
| **Сессия** | Живой режим игры: сценарий по сценам, НПС, музыка, заметки |
| **Хроники / Модули** | Управление хрониками и модулями, рекап для игроков, сессии и сценарии: фазы A → B → C |
| **Нити** | Открытые сюжетные нити по всем хроникам |
| **Слухи** | d20-таблицы слухов Элизиума и Грёз |
| **Звуковая библиотека** | Саундборд сессии: музыка, эффекты, пресеты по локациям |
| **Библиотека** | Справочник кланов и сект, дисциплин V20, психических способностей Numina, достоинств/недостатков, фактов биографии — создание/редактирование/удаление собственных записей прямо в интерфейсе |
| **Инструменты** | Учёт данных и валидация ссылок, настройки ИИ, руководство пользователя, бэкап городов и настроек |
| **Города** | Создание и переключение доменов хроники |
| **Поиск** | Полнотекстовый поиск по городу |

Плавающая кнопка **🎲** (правый нижний угол, доступна на любой странице) — быстрый бросок пула d10 по правилам V20, с подстановкой атрибутов/способностей/добродетелей выбранного персонажа.

## ИИ-провайдеры

Каждая функция генерации привязывается к провайдеру независимо (**Инструменты → ⚡ Назначение генераций**). Достаточно одного провайдера.

| Провайдер | Лучше для | Что нужно |
|-----------|-----------|-----------|
| **Claude** (Anthropic) | Художественная проза, нарратив | Вход через Claude Code или `ANTHROPIC_API_KEY` |
| **Gemini** (Google) | Проза, длинные сценарии | `GEMINI_API_KEY` + TgWsProxy — [инструкция](docs/gemini.md) |
| **OpenRouter** | Vision-анализ арта, резервный | `OPENROUTER_API_KEY` (есть бесплатные модели) |
| **GPT** (OpenAI) | Универсальный | `OPENAI_API_KEY` |

Ключи хранятся в `web/.env` (не в git). Настраиваются прямо в UI.

**При лимите (429)** генерация автоматически переключается на резервного провайдера и помечает, что ответ пришёл от резерва.

## Структура

```
cities/<город>/          ← данные города (персонажи, хроники, локации, архив)
  rules/                 ← правила этого города, в т.ч. словарь видов связи
system/                  ← правила, справочники, схемы (общие для всех городов)
tools/                   ← CLI-утилиты и миграции формата файлов
web/                     ← сервер Express + SPA-фронтенд
docs/                    ← документация
start.bat                ← точка входа (Windows)
```

Всё, кроме арта, — обычный Markdown: файлы можно читать, править и версионировать
любым внешним редактором. Когда формат меняется, старые файлы чинятся автоматически
миграцией при старте сервера (`tools/migrations/`).
